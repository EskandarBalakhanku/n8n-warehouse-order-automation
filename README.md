# Warehouse Order Automation | n8n

## Project Overview
An automated warehouse order processing and reporting workflow developed as part of the n8n Academy Quickstart (QS101) course.

## Key Features
- Scheduled and manual execution
- Warehouse REST API integration
- Conditional order filtering
- Automated order calculations
- Data Table management
- Discord notifications

## Technologies Used
- n8n
- REST API
- JavaScript
- JSON
- Data Tables
- Discord

## Getting Started
1. Import the workflow JSON into n8n.
2. Configure API and Discord credentials.
3. Connect your Data Table.
4. Configure your assessment ID.
5. Test the workflow manually.

## Project Status
Completed as an n8n Academy educational project.
